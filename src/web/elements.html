Structure: Every button sits inside a .wrap (position:relative). Color-glowing variants add a sibling .glow div (position:absolute, inset:0, z-index:0) whose box-shadow provides the color bloom. Glow isolation rule: When a button needs a color bloom, put it on the .glow wrapper div, not on the button itself. Applying box-shadow glow directly to a 2px border-radius element bleeds into the corners and softens the sharp edge. The wrapper absorbs the glow; the button stays sharp.

09
Raised & Inset Surfaces
Consistent 3D depth language across all UI
The Voltform UI uses a consistent physical depth metaphor. Raised surfaces sit above the page — buttons, toggles, number badges. Inset surfaces are pressed into it — inputs, checkboxes, range tracks. Never mix the two border patterns on the same element.
Raised
Raised surface pattern
background: linear-gradient(180deg, #LIGHTER 49%, #DARKER 50%) border-top: 1px solid [bright highlight] border-left: 1px solid [mid highlight] border-right: 1px solid [dark shadow] border-bottom: 1px solid [darkest shadow] box-shadow: 0 Npx 0 [pitch black]
Inset field
Inset surface pattern
background: rgba(0,0,0,0.5) border-top: 1px solid rgba(0,0,0,0.9) ← dark border-left: 1px solid rgba(0,0,0,0.7) ← dark border-right: 1px solid rgba(255,255,255,0.07) ← light border-bottom: 1px solid rgba(255,255,255,0.1) ← light box-shadow: inset 0 2px 4px rgba(0,0,0,0.8)

Timing & Easing Tokens
CSS transition / animation duration
Rule: Use the shortest duration that still feels intentional. Voltform UI is fast — nothing lingers. Button presses are 70ms, hover colour shifts are 120ms, entrances are 350–500ms. Always pair duration with the right easing curve — the wrong easing makes a fast animation feel slow and a slow animation feel abrupt.
